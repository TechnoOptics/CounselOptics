## 2. Verification discipline (non-negotiable, each learned from a defect)

1. Four gates, TRUE exit codes, never through a pipe:
   `npx tsc --noEmit > /tmp/t.log 2>&1; echo "TSC_EXIT=$?"`, same for
   `npx vitest run`, `npm run build`, `npm run test:audit-guards`.
   Use `grep -a` on the vitest log; a NUL byte has silenced grep before.
   Baseline on main today: 330 files, 5484 passed, 1 skipped, all four at 0.
2. Every guard you add gets MUTATED: break the code, confirm RED, restore,
   prove `git diff --stat` empty. A guard you did not watch fail is not
   evidence. Source-reading guards strip comments first
   (`tests/support/strip-comments.ts`) and assert a CALL, not a NAME; guards
   here have been satisfied by their own comment and by an import line.
3. Migrations are applied BEFORE the code that reads them is pushed, because
   PostgREST fails a whole request on a missing column. Then regenerate the
   fingerprint (`scripts/schema/fingerprint-hash.sql`, run server side) and
   correct the migration's banner in HEADING AND BODY. Half-corrected banners
   have happened three times. A CHECK constraint must never be recreated from
   a hard-coded list; read the live definition first.
4. No em dashes, no en dashes, no emoji anywhere (code, copy, commits, docs).
   Sweep with `grep -E` plus a positive control and READ the control's result;
   silent no-match sweeps have happened three times, once because perl needed
   `-CSD`.
5. Copy is calm and plain. Users are people under legal stress.
6. Render the artifact and look. Green tests missed two defects that were
   obvious on a rendered page; the letterhead was proven by rendering page one.
7. Agents: split "find" from "fix", commit per phase, run checks in the
   FOREGROUND (a stopped agent is never woken by a background command). Rate
   limits (429) have killed agents mid-flight; phased commits are what survives.
