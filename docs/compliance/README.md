# Advottic Compliance Program

This folder is Advottic's audit-readiness documentation for **SOC 2**, **ISO 27001**, and **HIPAA**. It reflects the codebase as of 2026-07-01.

> **Important:** These documents make Advottic *audit-ready*; they do not by themselves make it "certified" or "compliant." SOC 2 and ISO 27001 require external audits; HIPAA requires executed BAAs and a named Security Official. See the readiness assessment §7 for what only the business can do. **Do not publish "SOC 2 / ISO 27001 / HIPAA compliant" claims until they are actually attested/executed.**

## Ownership
All documents need a named **Security Official** and **Owner** sign-off, an effective date, and at least annual review. Retain all versions **6 years** (HIPAA §164.316(b)(2)).
